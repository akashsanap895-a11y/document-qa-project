About Project

This AI-based system allows users to upload documents and ask questions in natural language. It uses NLP and Generative AI to provide accurate answers instantly.

  • Keyword search misses context
  • Users need fast and accurate answers

Features

  • 🧠 NLP-based understanding
  • ⚡ Fast answer generation
  • 💬 Chat-based interface
  • 📊 Context-aware responses

  • Sentence Transformers

  • Streamlit
